# JumpGuy Unity

A 2D Unity platformer created as an introductory Unity assignment.

## Overview

JumpGuy is a small side-scrolling platform game built in Unity. The player runs, jumps, collects coins, avoids enemies and hazards, and reaches the finish trigger to win the level.

## What I Built

- 2D player controller with movement, jumping, sprite flipping, smoke particles, and jump sound
- Coin collection system with different coin values
- Score and lives tracking through a central game manager
- Game over and win states with UI panels
- Enemy behavior that chases the player and jumps across gaps
- Kill zones and player respawn/life loss logic
- Finish trigger for completing the level
- Main menu with start and quit actions
- Dynamic platform spawning through trigger zones
- Player, enemy, flag, idle, run, and jump animations

## Tech Stack

- Unity `2021.3.18f1`
- C#
- Unity 2D Physics
- TextMeshPro
- Universal Render Pipeline
